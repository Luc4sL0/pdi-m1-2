# Projeto M1.2 – Operações Pontuais e Filtragem Espacial

O trabalho propõe e avalia pipelines de processamento aplicados a imagens de melanomas, envolvendo inserção de ruído, transformação de intensidade, filtragem espacial e aguçamento.
